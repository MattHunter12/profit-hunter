# Profit Hunter

Profit Hunter is a personal finance brand starting with an accountant-backed offer for people who make decent money but still feel broke before payday.

Current product direction:

- Free lead magnet: Money Leak Finder
- Paid product: Paycheck Peace System
- Core story: map each paycheck before the checking account lies to you

## Files

- `docs/product-decision.md`: product choice, market rationale, offer ladder
- `docs/research-scorecard.md`: scored idea comparison
- `docs/launch-plan.md`: first 7-day validation plan
- `marketing/brand-story.md`: positioning, voice, narrative, content pillars
- `marketing/email-sequence.md`: lead magnet and nurture emails
- `marketing/content-ideas.md`: social and long-form content prompts
- `landing/index.html`: static landing page
- `landing/styles.css`: landing page styles
- `outputs/profit-hunter-money-leak-finder/money-leak-finder.xlsx`: free calculator workbook
